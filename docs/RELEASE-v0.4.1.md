# v0.4.1 — CI 跨平台修复 · 漂移提示不再误报

发布日期：2026-11-01

这是 0.4.0 的补丁版：只修跨平台与诊断噪音，不动记忆布局。

## 修复

- **Linux CI 失败**：`safeRelPath` 在 POSIX 上把反斜杠当普通字符，导致 `日\\x.md` 这类路径
  与 Windows 行为不一致；现在统一按 `/` 和 `\\` 都作分隔符解析，Windows 路径仍被拒绝。
  本地 202 项测试全绿，GitHub 的 Ubuntu 任务会重新验证。
- **doctor 漂移提示**：DSH 0.2.1-rc.5 不再提供旧 base 文档 `readDocument` 时，原先会把快照里
  所有行都列成“缺失”，看起来像坏了几十项；现在标记为 `skipped`，doctor 只提示
  「未完整检测（文档不可读）」，不再误报缺行。
- 生成物一致性仍由 `npm run check` 保证，不依赖运行时文档。

## 升级

拉取后重启 DSH；无需迁移记忆。`/cyrene 诊断` 的漂移行会变成简短提示。

## 验证

- 202 项测试通过；`npm run check` 生成一致。
- 新增跨平台 `safeRelPath` 断言；漂移测试覆盖 skipped 分支。
