# v0.3.0 — 月档/年档自动创建 · 夜梦读取真实对话

发布日期：2026-11-01

这次解决两件“明明聊了很多，却没记住”的问题：月档不再只等月末、夜梦不再只依赖稀疏的日档。

## 月档/年档自动创建

- 每次启动/维护都会确保当前月文件存在：`月/YYYY/YYYY-MM.md`（`status: open` 骨架）；
- 月末维护把骨架替换成按五育汇总的正式月档；跨年 1 月自动给上一年追加「年轮定格」；
- 已有正式月档或人工补记不会被覆盖；
- 新增 `/cyrene 月档`（`roll`）：立即创建/整理当前月与年度文件；
- 夜梦规程明确：**月档/年轮由宿主生成，不要用 `memory_fs` 写 `月/` 或 `年/`**，避免再出现“余页草稿代替正式月档”。

当前数据核对：

- `月/2026/2026-10.md`：60 条、12 天，已由月末自动整理；
- `月/2026/2026-11.md`：本月骨架已创建；
- `年/2026.md`：存在（含 10 月五育体检）。

## 夜梦读取真实对话

- 夜梦原先只读日档；如果白天模型没调用 `memory_write`，聊过的事就丢了；
- 现在夜梦会读取**启用中会话今天的对话摘录**（只取 user/assistant 文本，去掉系统上下文与工具调用，
  单会话最多 30 句、总长 ≤12000 字），作为“原始素材”交给六阶段整理；
- 摘录只用于提炼记忆，不会原样写进日档；梦志仍与日档分开；
- 提示词明确来源可以是「今晚的会话摘录」，所以模型白天没记的重要对话，晚上还有一次补救机会。
