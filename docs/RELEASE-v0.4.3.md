# v0.4.3 — 修复思源日档缺失

发布日期：2026-11-01

0.4.0 迁移后，思源里部分日档没有出现。原因有两个：

1. **空日没有文档**：条目同步只为“有 Entry 的日期”建文档；10-28、10-30 这类没有条目的
   空日就缺了。
2. **迁移后的镜像状态残留**：旧状态里的文档映射把一批日档指到了 `/余页/10/...` 下，
   新路径下自然看不到。

## 修复

- 新增 `syncDayShells`：维护 tick 会为**本地每一天**（含空日）确保
  `/一页永恒/岁月涟漪/日档/...` 文档存在；空日正文写「这一天没有写入记忆」；
- 清理 `/一页永恒/余页/10/...` 下误挂的日档副本，重置镜像状态后按新路径全量重建；
- 实测思源现在 10 月 14 天齐全（10-18 到 10-31），月响、年轮、梦境路径正常。

## 验证

- 202 项测试通过；`npm run check` 生成一致。
- 思源 SQL 核对：日档 14 篇、月响 2 篇、年轮 1 篇、梦境 14 篇。

## 升级

拉取后重启 DSH；维护 tick 会自动补齐缺失的空日。若想立刻重建：

```pwsh
# 在会话里
/cyrene 同步
```

旧的 `/余页/10/...` 副本已清理；本地日档数据不受影响。
