# v0.2.4 — 失效会话不再出现在夜梦列表

发布日期：2026-10-29

本次只修设置面板的夜梦会话识别，不动记忆、不动人设、不需要迁移。

## 修复

- 夜梦列表不再展示 **DSH 里已经被删除的旧会话**：
  - 之前登记表/旧日程里的 `session-944fe39a…`（2026-10-22「昔涟，晚上好。」那段）
    在 DSH 会话存储里已经不存在，却仍显示成「会话 session-…」；
  - 现在以 DSH 的会话清单为准：找不到的会话直接隐藏（不会误删设置，只是不显示）。
- 短会话 id 改成有意义的形式：去掉 `session-` 前缀，显示 UUID 前 8 位（如 `944fe39a…`），
  不再所有行都显示 `session-…`。
- 没有标题的会话显示「未命名会话（短 id）」；列表提示改为「点一行打开会话；勾选框只开关夜梦」。
- 测试：194 项（新增「已删除会话不展示」断言）。

## 升级

拉取后重启 DSH，设置面板重新加载即可；记忆与会话数据不变。
