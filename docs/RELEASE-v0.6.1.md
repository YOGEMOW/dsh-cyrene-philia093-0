# v0.6.1 — 记忆/整理的中文命令

发布日期：2026-11-01

`/memory` 和 `/dream` 之前只有英文，表格里红框那两个确实没有中文写法。现在补上：

| 英文 | 中文 |
|---|---|
| `/memory` | `/cyrene 记忆` |
| `/dream` | `/cyrene 整理` |

## 说明

- `/cyrene 记忆`：看看四问锚点、五育统计、最近记忆；
- `/cyrene 整理`：不等晚上，现在整理一次；
- `/cyrene 月响` 仍是月度/年度文档整理；
- 原来的 `/cyrene 整理` 曾模糊地当作“月响”别名，现已明确让给“立即整理”，月响请用
  `/cyrene 月响`（或 `roll`）；
- `/cyrene 帮助` 已列出这两个中文写法；设置面板/README 表格同步更新。

## 验证

- 209 项测试通过；已加中文 `记忆` / `整理` 的命令测试。
