# v0.2.1 — 命令中文化与帮助

发布日期：2026-10-25

本次只改命令的可用性和提示，不动记忆格式、不迁移数据。

## 新增/调整

- `/cyrene` 支持**中文子命令**，也保留英文写法：
  - `帮助`（help）：列出所有命令；
  - `诊断`（doctor）：体检；
  - `同步`（sync）/ `备份`（backup）；
  - `恢复`（restore），加 `强制` 才覆盖锚点/梦志；
  - `夜梦`（dreams）、`开启夜梦` / `关闭夜梦`；
  - `开卷 确认 <原因>`（new-volume）：记录人格边界。
- 输入提示改为中文短句：`帮助｜诊断｜同步｜备份｜恢复｜夜梦｜开卷`，不再是一长串英文参数。
- 无参数或看不懂的输入会显示中文帮助，而不是一句生硬的“用法”。
- 英文名继续可用，老习惯不受影响。

## 升级方式

拉取新版本后重启 DSH；无需迁移记忆。

## 验证

- 193 项测试通过；`npm run check` 生成一致。
- 新增中文别名/帮助测试；命令仍保持 preset 作用域，标准模式不可见。
