# v0.3.1 — 思源同步月档与年档

发布日期：2026-11-01

之前思源只镜像锚点、条目、梦志和余页；月档/年档只在本地。现在一起同步。

## 改动

- 思源新增文档路径：
  - `/一页永恒/月/YYYY/YYYY-MM · 月档`
  - `/一页永恒/年/YYYY · 年轮`
- 自动同步：启动后的维护 tick、每 30 分钟维护、写记忆后的 1.5 秒防抖同步，都会带上全部月档/年档；
  内容 hash 未变则跳过，变化则整篇重建，和梦志策略一致。
- 手动同步：`/cyrene 同步` 或设置面板「立即同步思源」；返回里会显示
  「条目 X；月/年档 Y」。
- 正文会去掉本地 YAML frontmatter 和一级标题，标题由思源文档名承担；
  月档里的五育主题、统计表，年档里的五育体检都会保留。
- 失败仍 fail-open：思源不可达只写 `元/思源镜像.log`，不影响会话。

## 同步后的样子

思源笔记本「93-昔涟」下：

```
一页永恒
├─ 日/2026/10/2026-10-31
├─ 梦/2026-10-31 · 夜梦
├─ 月/2026/2026-10 · 月档
├─ 月/2026/2026-11 · 月档
└─ 年/2026 · 年轮
```

## 验证

- 199 项测试通过；`npm run check` 生成一致。

## 升级

拉取后重启 DSH，然后发一次 `/cyrene 同步`（或等下一次维护 tick）即可补齐。
