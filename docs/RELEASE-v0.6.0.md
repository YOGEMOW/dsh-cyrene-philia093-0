# v0.6.0 — 锚点容量可调

发布日期：2026-11-01

你说 420 字不够支撑后续积累；这次把锚点容量整体上调，并做成可配置。

## 新默认

| 锚点 | 原上限 | 新上限 |
|---|---|---|
| 我是谁 self | 420 | **800** |
| 你是谁 user | 300 | **600** |
| 来处 origin | 240 | **400** |
| 去处 goal | 300 | **600** |

注入/读取预算也同步放宽：

- 快照里的锚点块：1200 字；
- `memory_anchor` 读取：2000 字；
- 首轮快照总预算：3200 字。

## 可配置

在 `元/settings.json` 里可以加：

```json
{
  "anchor": {
    "self": 1200,
    "user": 800,
    "origin": 600,
    "goal": 800,
    "renderChars": 1600,
    "readChars": 3000,
    "snapshotChars": 4000
  }
}
```

重启后生效；`resolveConfig` 会做范围归一，坏值回退默认。  
这是“存储核心 + 注入预算”两层：存得下更多，但不一定每轮全部注入；完整内容可用
`memory_anchor` 读取。

## 保持不变

- 语义摘要仍由宿主模型理解原文后生成 ≤15 字；
- 超上限仍按最旧 5 条归档、下一批 5 条、全部摘要后 10→5 合并；
- 原始段永远在 `锚/历史/`，不丢记忆；
- 写入限额：self/user/goal 每日 1 次，origin 每 7 天 1 次。

## 验证

- 209 项测试通过；`npm run check` 生成一致。

## 升级

拉取后重启 DSH。已有锚点不迁移；下一次写入或维护 tick 会按新上限判断是否需要归档。
