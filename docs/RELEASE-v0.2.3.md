# v0.2.3 — 夜梦会话列表可辨认、可点开

发布日期：2026-10-26

本次只改设置面板里的「夜梦与定时」会话列表，不动记忆格式、不动人设、不需要迁移。

## 改动

- 每个会话不再只显示 `session-…` 加一句最近聊天：
  - 显示**会话标题**（读 DSH 会话标题，没有标题时用最近一句）；
  - 显示**工作区/项目名**、短会话 id、最近活动时间；
  - 标注 `已排程`、`未登记`；
  - **点这一行可以直接打开那个会话**（勾选框仍然只负责开关夜梦，不会误触跳转）。
- 列表会补上其他昔涟会话（未登记），可以直接勾选纳入夜梦。
- 标题读取失败时自动退回原来的最近一句，不影响面板加载。

## 验证

- 194 项测试通过（新增标题/工作区/未登记列表测试）；`npm run check` 生成一致。

## 升级

拉取后重启 DSH 即可；记忆与设置不变。
